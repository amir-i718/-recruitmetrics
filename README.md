RecruitMetrics
Quantifying the Path to College Basketball

RecruitMetrics is a full-stack basketball recruiting analytics platform that helps high-school athletes identify realistic college matches and evaluate their fit using data-driven insights.

Built with Python (Flask/FastAPI), SQLite, and a modern front-end in HTML/CSS/JS, RecruitMetrics combines athletic, academic, and contextual factors into a single composite metric — the RecruitScore — to visualize where a player stands across over 1,000 colleges and 400+ high-school/AAU leagues.

Features
RecruitScore Engine: Calculates a composite score using GPA, height, position, league competitiveness, and academic–athletic balance.
College Fit Matching: Suggests schools based on athletic profile and academic data.
Dynamic UI Dashboard: Interactive interface for player input, data visualization, and school recommendations.
League and Conference Database: Normalized database of 1,000+ colleges and 400+ high-school/AAU leagues.
Data Normalization: Scales raw scores to a 0–100 metric using statistical normalization.

Tech Stack
Frontend	HTML, CSS, JavaScript (Vanilla)
Backend	Python (Flask / FastAPI)
Database	SQLite3
